## ข้อ 1 — ใส่ PromptPay จริง (15 นาที) · ต้องทำก่อนครูจ่ายเงิน

หน้า "ขอเปิด Pro" จะไม่แสดง QR เลยจนกว่าตัวแปรสองตัวนี้จะมีค่าที่ผ่านการตรวจรูปแบบ

### 1.1 ยืนยันเลขกับ Ing
1. Ing เปิดแอปธนาคาร → PromptPay → ดูว่าผูกกับ **เบอร์โทร** หรือ **เลขบัตรประชาชน** และชื่อบัญชีสะกดยังไง
2. ให้คนในทีมอีกคนลองโอน 1 บาท → **ก่อนกดยืนยัน** ดูว่าชื่อผู้รับตรงกับที่ Ing บอกไหม → ตรงแล้วค่อยโอน (Ing โอนคืน)
3. Ing ส่งเลข + ชื่อผู้รับให้เต้ (เลข PromptPay เป็นข้อมูลที่ตั้งใจเผยแพร่ ส่งในแชทได้ ไม่ใช่ secret)

### 1.2 ตั้ง Variables ใน GitHub
1. https://github.com/Tasachii/solo-tutor → **Settings** → **Secrets and variables** → **Actions**
2. กดแท็บ **Variables** (ไม่ใช่ Secrets — สองค่านี้แสดงบนเว็บให้ครูเห็น ไม่ใช่ความลับ)
3. **New repository variable** ทีละตัว

| Name | Value | เงื่อนไขที่โค้ดตรวจ (`src/platform/config.ts`) |
|---|---|---|
| `VITE_SOLO_PROMPTPAY` | เบอร์ 10 หลัก เช่น `0812345678` หรือเลขบัตร 13 หลัก | ตัวเลขล้วน ไม่มีขีด ไม่มีเว้นวรรค · ผิดรูปแบบ = ระบบมองว่าว่าง QR ไม่ขึ้น |
| `VITE_PROVIDER_LEGAL_NAME` | ชื่อผู้ให้บริการที่ครูเห็น เช่นชื่อบัญชีที่ปลายทางเห็น | ยาว 2–160 ตัว · **ห้ามมีคำว่า** `example`, `todo`, `xxx` (โค้ดปฏิเสธ) |

### 1.3 Deploy ใหม่
**Actions** → **Verify and deploy** → **Run workflow** → branch `main` → Run
รอ 4–8 นาทีจนเป็นเครื่องหมายถูกเขียว (ค่า Variables เข้าเว็บตอน build เท่านั้น ไม่ deploy ใหม่ = ค่าไม่เข้า)

### 1.4 ตรวจ
1. เปิดเว็บในหน้าต่าง **ไม่ระบุตัวตน** (กัน cache)
2. เข้าสู่ระบบบัญชีครูของทีม (โหมดข้อมูลจริง) → เมนู → บัญชีครู → **ขอเปิด Pro**
3. ต้องเห็น QR + ชื่อผู้รับตรงกับที่ Ing บอก
4. สแกน QR ด้วยแอปธนาคาร → ต้องขึ้นชื่อผู้รับถูกต้อง → **ยกเลิก ไม่ต้องโอน**

**ถ้า QR ไม่ขึ้น**: เช็คว่าอยู่ในแท็บ Variables จริง · ชื่อตัวแปรพิมพ์ใหญ่ทั้งหมด · เลขไม่มีขีด · ชื่อไม่มีคำต้องห้าม แล้ว Run workflow ใหม่

## ข้อ 2 — LINE Developers (30 นาที)

**ทำตามลำดับนี้เท่านั้น** ถ้าออก token ใหม่หลังกรอกในแอป ต้องกรอกซ้ำ

### 2.2 ออก Channel access token ใหม่

### 2.3 ตั้ง Webhook
1. แท็บ **Messaging API** → **Webhook settings** → **Edit** → ใส่
   `https://qbuafdbmpkffzbkqoysb.supabase.co/functions/v1/line-webhook` → **Update**
2. เปิดสวิตช์ **Use webhook**
3. กด **Verify** → ต้องขึ้น **Success**

### 2.4 กรอกค่าใหม่ในแอป
เว็บจริง → เข้าสู่ระบบบัญชีครูของทีม (โหมดข้อมูลจริง) → **เมนู → เชื่อม LINE OA** → กรอก Channel secret + access token → บันทึก
ค่าถูกเข้ารหัสเก็บในฐานข้อมูล ไม่ได้อยู่ใน repo

### 2.5 ปิดข้อความอัตโนมัติ
https://manager.line.biz → OA Solo Tutor → **Settings** → **Response settings**
- Greeting message: **ปิด** (ไม่งั้นทักทายทับตอนผู้ปกครองเพิ่มเพื่อน)
- Auto-response: **ปิด** (ไม่งั้นบอทตอบทับรหัส 6 หลัก)
- Webhook: **เปิด** · Chat: เปิดถ้าจะใช้ตอบซัพพอร์ตเอง

### 2.6 ลบร่องรอย
ลบ secret/token ที่จดชั่วคราว · ลบบรรทัดค่าเก่าใน `.env` ในเครื่องถ้ามี

**ถ้า Verify ไม่ผ่าน**
- ขึ้น status อื่นที่ไม่ใช่ 200 → Supabase Dashboard → Edge Functions → `line-webhook` → Logs (อย่าส่ง log ที่มี token)
- timeout → ลองอีกครั้งเดียว ถ้ายัง timeout ให้จดไว้แล้วไปข้อ 3 ต่อ (เกี่ยวกับ C-01 ที่ยังค้าง) และ **ห้ามพูดบนเวทีว่า "ผ่านทุก endpoint"**

## ข้อ 3 — ทดสอบส่งจริงถึงโทรศัพท์ (15 นาที)

หลักฐานเดียวที่ทำให้พูดได้ว่า "ส่งผ่าน LINE OA ได้จริง" ถ้าไม่ผ่าน บนเวทีให้ใช้ "ครูคัดลอกข้อความไปส่งเอง" และไม่พูดถึง OA

### 3.1 สร้างรายชื่อทดสอบ
1. แอป (บัญชีทีม โหมดจริง) → หน้านักเรียน → เพิ่ม 1 คน: `น้องทดสอบ OA` / ผู้ปกครอง `ผู้ปกครองทดสอบ` / รายครั้ง 100
2. เปิดหน้ารายละเอียดคนนี้ → ปุ่มสร้างรหัสเชื่อม LINE → ได้ **รหัส 6 หลัก** (หมดอายุ 24 ชม.)

### 3.2 จับคู่
1. โทรศัพท์ทีมที่ยังไม่เคยแอด OA → เพิ่มเพื่อน `@458gfbxa`
2. เปิดแชทกับ OA → **พิมพ์รหัส 6 หลัก** → ส่ง
3. กลับมาที่แอป → กดตรวจสถานะ → ต้องขึ้นว่าเชื่อมแล้ว

### 3.3 ส่ง 1 ครั้ง
1. บันทึกคาบให้คนนี้ 1 คาบ → ออกบิล
2. **อ่านข้อความที่ร่างให้ทั้งหมดก่อน** (นี่คือสิ่งที่ผู้ปกครองจะเห็น)
3. ใช้ปุ่ม **ส่งใน LINE ของแถวนั้นคนเดียว** — มีอยู่แล้วในทุกแถวของแท็บค้างจ่ายและในการ์ดข้อความ
   ปุ่ม **ส่งแจ้งยอดทั้งหมดผ่าน LINE OA** เป็นการส่งทั้งชุด **ห้ามใช้ตอน demo** เพราะเรื่องที่เล่าบนเวทีคือครูอ่านแล้วกดส่งทีละคน
4. กด **ครั้งเดียว** รอ 5–10 วินาที → โทรศัพท์ต้องได้ **1 ข้อความ** และแอปขึ้นว่าส่งสำเร็จ
5. ถ้าแอปยังไม่ขึ้นผล → กดตรวจผลเดิม **ห้ามกดส่งซ้ำ** (ได้ 2 ข้อความ = idempotency พัง ต้องแจ้งทันที)

### 3.4 เก็บกวาด
ลบ `น้องทดสอบ OA` ออก · จดว่าการส่งนี้เป็นการทดสอบของทีม ไม่นับใน traction
