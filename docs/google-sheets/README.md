# สำรองข้อมูลลง Google Sheets ของคุณเอง

ข้อมูลอยู่ในเครื่องคุณเป็นหลัก ชีตเป็น **สำเนา** ที่คุณเปิดดูเองได้และใช้กู้คืนได้
Solo Tutor ไม่ได้เก็บข้อมูลของคุณไว้ที่ไหนเลย — ชีตนี้อยู่ใน Google Drive ของคุณ

ตั้งครั้งเดียว ใช้ได้ตลอด ใช้เวลาประมาณ 5 นาที

## 1 · สร้างสเปรดชีต

เปิด [sheets.new](https://sheets.new) ตั้งชื่ออะไรก็ได้ เช่น "Solo Tutor — ข้อมูลลูกค้า"

## 2 · วางสคริปต์

ในสเปรดชีต เมนู **ส่วนขยาย → Apps Script**
ลบโค้ดที่มีอยู่ทิ้ง แล้ววางเนื้อหาทั้งหมดจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ · กดบันทึก

## 3 · ตั้งรหัสของคุณ

ในหน้า Apps Script: **ไอคอนฟันเฟือง (การตั้งค่าโปรเจกต์) → คุณสมบัติของสคริปต์ → เพิ่มคุณสมบัติ**

| ช่อง | ใส่ |
|---|---|
| คุณสมบัติ | `TOKEN` |
| ค่า | รหัสอะไรก็ได้ที่เดายาก เช่น `solo-8f3k-92xq-4m` |

กดบันทึก · **จำรหัสนี้ไว้** ต้องเอาไปใส่ในแอป

## 4 · Deploy เป็น Web App

**Deploy → การทำให้ใช้งานได้ใหม่ → ประเภท: เว็บแอป**

| ตั้งค่า | เลือก |
|---|---|
| ดำเนินการในชื่อ | ฉัน (อีเมลคุณ) |
| ผู้มีสิทธิ์เข้าถึง | **ทุกคน** |

"ทุกคน" หมายถึงใครก็ตามที่รู้ URL ยิงเข้ามาได้ — จึงต้องมี `TOKEN` กันไว้อีกชั้น
Google จะขออนุญาตเข้าถึงสเปรดชีตครั้งแรก กด **อนุญาต** (หน้าจอเตือน "ยังไม่ได้ยืนยัน" ให้กด ขั้นสูง → ไปที่โปรเจกต์)

คัดลอก **URL ของเว็บแอป** ที่ได้ หน้าตาแบบนี้:
`https://script.google.com/macros/s/AKfycb.../exec`

## 5 · ใส่ในแอป

เมนู (⋯) → **สำรองลง Google Sheets** → วาง URL และรหัส → กด **ทดสอบและบันทึก**

เสร็จแล้ว ทุกครั้งที่ข้อมูลเปลี่ยนแอปจะส่งขึ้นชีตให้เอง (อย่างช้าทุก 30 วินาที)

## แท็บที่จะขึ้นในชีต

| แท็บ | มีอะไร |
|---|---|
| รายชื่อ | ลูกค้าทุกคน วิธีเก็บเงิน ราคา แพ็กคงเหลือ |
| ตาราง | ทุกคาบ/งาน วันเวลา และสถานะ |
| บิล | ทุกใบ ยอด จ่ายแล้ว คงเหลือ เลขใบเสร็จ |
| สรุปรายเดือน | ยอดควรได้ · เข้าแล้ว · คงเหลือ ของแต่ละเดือน |
| `_ข้อมูลสำรอง` (ซ่อนไว้) | สำเนา JSON ทั้งก้อน ใช้กู้คืน — ไม่ต้องแก้เอง |

## คำถามที่พบบ่อย

**ปลอดภัยแค่ไหน** — ชีตอยู่ใน Drive ของคุณ คนอื่นเปิดไม่ได้เว้นแต่คุณแชร์ · URL เว็บแอปเป็นความลับ ใครได้ไปพร้อมรหัสจะเขียนทับชีตคุณได้ ถ้าสงสัยว่าหลุด ให้ Deploy ใหม่เพื่อเปลี่ยน URL และเปลี่ยน `TOKEN`

**โหมดเดโมส่งขึ้นชีตด้วยไหม** — ไม่ ข้อมูลสมมติจะไม่ไปปนกับของจริง

**ถ้าไม่มีเน็ต** — แอปยังใช้ได้ปกติ ค่อยส่งขึ้นชีตเมื่อกลับมาออนไลน์

**แก้ในชีตแล้วแอปเปลี่ยนตามไหม** — ไม่ ชีตเป็นสำเนาอย่างเดียว การคิดเงินทั้งหมดเกิดในแอป
