# Runbook สาธิต LINE OA — Solo Tutor

เอกสารนี้แยกการสาธิตเป็นสองแบบ แบบแรกใช้ข้อมูลจำลองและไม่แตะ LINE จริง เหมาะสำหรับ pitching ส่วนแบบที่สองใช้ OA `@458gfbxa` และต้องทำเฉพาะกับบัญชี LINE ของทีมที่อนุญาต

## A. เดโมปลอดภัยสำหรับ pitching

1. เปิด [Solo Tutor](https://tasachii.github.io/solo-tutor/) แล้วเปิดเมนู **กู้คืนจากไฟล์**
2. เลือกไฟล์ `solo-demo-kru-ploy-5.json` จากโฟลเดอร์ `Downloads/Solo-Pitch-Kit-20260908` และกดยืนยันกู้คืน ระบบจะแสดงครูพลอยกับนักเรียน 5 คน
3. ตรวจว่าหน้ายังมีป้าย **ข้อมูลจำลอง** อย่ากดเริ่มใช้จริงระหว่างการนำเสนอ
4. เปิดเมนู **เชื่อม LINE OA** หน้าเดโมจะแสดงกรอบ “ตัวอย่างการเชื่อม LINE OA” และข้อความว่าการจับคู่เป็นข้อมูลจำลองและไม่ส่ง LINE จริง
5. อธิบายลำดับบนจอ: ครูส่งลิงก์เพิ่มเพื่อน → ระบบออกรหัส 6 หลัก → ผู้ปกครองพิมพ์รหัส → ครูเป็นคนตรวจและกดส่งบิล
6. กด **จำลองผู้ปกครองพิมพ์รหัส** สถานะจะเปลี่ยนเป็น “เชื่อมแล้ว (จำลอง)” การเปลี่ยนนี้อยู่เฉพาะหน้าจอ ไม่บันทึกลงสมุดข้อมูล
7. กด **ดูร่างบิลในหน้าแอดมิน** เพื่อโชว์ข้อความที่ระบบร่างจากข้อมูลที่ครูยืนยัน
8. ระหว่าง pitching ไม่กดปุ่มเปิด LINE หรือส่งด้วย LINE OA ใช้ข้อความร่างบนจออธิบาย flow แทน จึงไม่มีโอกาสส่งถึงบุคคลจริง
9. หากต้องเริ่มใหม่ กลับหน้าเชื่อม LINE แล้วกด **เริ่มตัวอย่างใหม่** หรือโหลดหน้าใหม่

## B. เปิด webhook ของ OA `@458gfbxa`

สถานะที่ยืนยันแล้วคือ server มี channel ของ Solo Tutor และตรวจ token/Webhook endpoint ผ่าน ยังไม่ได้ยืนยันจากหลักฐานรอบนี้ว่าสวิตช์ Use webhook เปิดอยู่ และยังไม่ได้จับคู่หรือส่งข้อความจริง

1. เข้าสู่ [LINE Developers Console channel 2011503954](https://developers.line.biz/console/channel/2011503954)
2. เลือกแท็บ **Messaging API** แล้วเลื่อนไป **Webhook settings**
3. ตรวจ Webhook URL ให้ตรงกับ:

   ```text
   https://qbuafdbmpkffzbkqoysb.supabase.co/functions/v1/line-webhook
   ```

4. ถ้า URL ไม่ตรง ให้วาง URL นี้แล้วกด **Update**
5. กด **Verify** รอจน LINE แสดง **Success** หากขึ้น Failed ให้หยุดตรงนี้ ตรวจ URL และลองใหม่
6. เปิด **Use webhook** ให้เป็น Enabled/On
7. เปิด [LINE OA Manager `@458gfbxa`](https://manager.line.biz/account/@458gfbxa/) → **Settings → Response settings**
8. เปิด Webhook และปิด Greeting message กับ Auto-response ระหว่างทดสอบ เพื่อไม่ให้ข้อความจาก LINE OA Manager ซ้อนกับ webhook
9. กลับ [หน้าตั้งค่า LINE OA ใน Solo Tutor](https://tasachii.github.io/solo-tutor/#/app/settings/line) เข้าบัญชีครูเดิมในโหมดข้อมูลจริง แล้วกด **ตรวจสถานะอีกครั้ง**
10. ตรวจชื่อ OA ว่าเป็น **Solo Tutor** และสถานะไม่เป็น invalid/setup failed หาก active อยู่แล้วไม่ต้องวาง credential ซ้ำ

## C. ทดสอบ LINE จริงกับทีมหลังเปิด webhook

1. ใช้รายชื่อทดสอบที่ไม่มีข้อมูลผู้ปกครองจริง และใช้บัญชี LINE ของเจ้าของหรือทีมที่ยินยอม
2. ใน Solo Tutor กด **สร้างรหัสเชื่อม** ให้รายชื่อทดสอบ เก็บรหัสไว้เฉพาะทีม
3. จากบัญชี LINE ทดสอบ เพิ่มเพื่อน OA `@458gfbxa` ต้องได้รับข้อความขอรหัส 6 หลัก
4. พิมพ์รหัส ต้องได้รับข้อความว่าเชื่อมแล้ว
5. กลับ Solo Tutor กด **ตรวจสถานะอีกครั้ง** รายชื่อต้องขึ้น “เชื่อมแล้ว”
6. สร้างข้อความทดสอบที่ไม่มีชื่อ ยอด หรือข้อมูลจริง กด **ส่งด้วย LINE OA** เพียงหนึ่งครั้ง
7. รอจนรายการในแอปเปลี่ยนเป็นส่งแล้ว ตรวจบัญชี LINE ทดสอบว่าได้รับครั้งเดียว หากผลค้างให้กด **ตรวจสอบผลส่ง LINE OA** ห้ามกดส่งซ้ำหรือเปิด LINE ส่งเอง
8. พิมพ์ `หยุด` จากบัญชีทดสอบ แล้วตรวจว่าการส่งครั้งถัดไปถูกปฏิเสธเพราะผู้รับยกเลิก

ขั้นตอนส่วน C ยังไม่ได้ดำเนินการหรือยืนยันผลในรอบนี้ จึงห้ามใช้เป็นคำกล่าวว่า LINE ส่งจริงผ่านแล้วจนกว่าจะเก็บหลักฐานจากบัญชีทดสอบ

ก่อนเชิญผู้ปกครองจริง ให้ออก Channel secret และ Channel access token ใหม่ใน LINE Developers แล้วเชื่อมใหม่ผ่านฟอร์ม Solo Tutor เนื่องจากค่าเดิมเคยปรากฏนอกช่องทางลับระหว่างการตั้งค่า อย่าใส่ค่าใหม่ในแชท เอกสาร screenshot หรือ repository
