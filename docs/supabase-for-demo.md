# ควรซื้อ Supabase Pro เพื่อ Demo แข่งเคสไหม

**คำแนะนำสำหรับ Solo Tutor ตอนนี้: ใช้ Free ต่อก่อน** เพราะเป้าหมายเป็นการสาธิตด้วยข้อมูลสมมติ แอปมี Demo ในเครื่อง และเส้นทางบัญชี/LINE/แพ็กชำระเงินทดสอบด้วย mock ได้ การอัปเกรดไม่จำเป็นต่อการโชว์ปัญหาของครู คุณค่าของผลิตภัณฑ์ หรือโมเดลรายได้

ตรวจเอกสารทางการ 8 กันยายน 2569 ยังไม่ได้เปลี่ยนแพ็กหรือก่อค่าใช้จ่ายให้

**Pro $25 ไม่ได้รวม PITR** เป็น add-on แยก และการ restore database backup ไม่คืนไฟล์ Storage ที่ถูกลบไปให้เอง ไม่ต้องซื้อ PITR เพื่อสาธิตข้อมูลสมมติ ([Database Backups](https://supabase.com/docs/guides/platform/backups))

## เมื่อไรจึงคุ้มที่จะซื้อ

- อยู่ Free ต่อถ้าเส้นทางหลักคือเช็คชื่อ → บิล → ส่งข้อความร่าง → ตรวจยอดจำลอง → ใบเสร็จ และมีเวลาซ้อม/ปลุกโปรเจกต์ก่อนแข่ง
- พิจารณา Pro ในรอบบิลช่วงแข่งขัน ถ้า live login/sync หลายเครื่องเป็นหัวใจที่กรรมการต้องเห็น หรือทีมอยากจ่ายค่าลดภาระดูแล inactivity ให้ตรวจ billing ของ organization และจำนวน projects/add-ons ก่อนอัปเกรด ไม่สมมติว่ายอดรวมทุกกรณีเท่ากับ $25
- ประเมินใหม่เมื่อมีครูใช้ข้อมูลจริงและเริ่มจ่ายเงิน: backup/restore, การไม่พัก, quota และระยะเก็บ log มีคุณค่ามากขึ้น แต่ Pro ไม่แก้ RLS ผิด บั๊กซิงก์ อินเทอร์เน็ตในสถานที่ SMTP หรือเอกสารบริการ

ไม่มีหลักฐานจากรอบ QA นี้ว่า workload ของ Demo ต้องซื้อ compute เพิ่ม คำแนะนำให้ใช้ Free เป็นการตัดสินตามลักษณะ Demo ไม่ใช่ผล load test production

## เตรียมวันแข่งให้มั่นใจกว่าการซื้อแพ็กอย่างเดียว

1. ก่อนแข่ง 1 วัน เปิดโปรเจกต์และซ้อมบนเครื่อง/เบราว์เซอร์ที่จะใช้จริง ถ้าจะโชว์ cloud ให้ลองบัญชีสมมติสองเครื่องและตรวจว่าสำเนาที่เห็นเป็นชุดเดียวกัน
2. เปิด Demo ให้ assets และฟอนต์ติดตั้งครบ แล้วลองตัดเน็ต/เปิดใหม่ ชุดทดสอบ Chromium ครอบคลุมเส้นนี้ แต่ควรซ้อมเครื่องจริงด้วย
3. เก็บไฟล์ backup, ไฟล์ recovery สำหรับบัญชีสมมติ และคู่มือไว้กับทีม อย่าให้การสาธิตพึ่งอีเมล reset สดต่อหน้ากรรมการ
4. ใช้ scenario เดิมที่ซ้อมแล้ว ตรวจเดือน/ยอด/ชื่อนักเรียนสมมติให้พร้อมก่อนเริ่ม ไม่รีเซ็ตหรือ deploy เปลี่ยน schema ในนาทีสุดท้าย
5. ถ้า network มีปัญหา ใช้ Demo ออฟไลน์แสดง core flow และอธิบายชัดว่าส่วนไหนเป็น simulation ส่วนไหนทดสอบกับ server จริงแล้ว ไม่กล่าวว่า mock approval คือการรับเงินจากธนาคาร
6. หากต้องการหลักฐานสำรองสำหรับเวที ให้บันทึกวิดีโอสั้นจากรอบซ้อมไว้ วิดีโอการนำเสนอพร้อมเสียงยังไม่ได้ผลิตในงานนี้

สำหรับโจทย์แข่งนี้ **เงินก้อนแรกยังไม่จำเป็นต้องเป็น Supabase Pro** ให้ตัดสินจากรูปแบบการโชว์ live และความเสียหายหากต้องสลับเข้า Demo ไม่ใช่ความรู้สึกว่าแอปที่เชื่อม Supabase ต้องใช้แพ็กเสียเงินเสมอ
