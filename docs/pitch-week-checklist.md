## LINE OA ที่ต่อได้วันนี้

- เชื่อมฝั่งเซิร์ฟเวอร์กับ **Solo Tutor `@458gfbxa`** แล้ว และทดสอบ endpoint จาก LINE ผ่าน
- หน้าจอ Demo จำลองการจับคู่ได้โดยไม่เรียก Supabase/LINE
- เจ้าของเข้า [Messaging API](https://developers.line.biz/console/channel/2011503954/messaging-api) เปิด **Use webhook** และกด **Verify → Success**
- จากนั้นทดสอบกับ LINE ของทีม: เพิ่มเพื่อน → รับรหัส 6 หลักจากแอป → พิมพ์ในแชท → ตรวจสถานะจับคู่ → ครูตรวจบิลและกดส่ง
- ยังไม่มีหลักฐานการจับคู่หรือส่งบิลถึงบัญชี LINE จริง จึงไม่เรียก mock test ว่าส่งจริงสำเร็จ
- ขั้นตอนละเอียด: [line-demo-runbook.md](line-demo-runbook.md)

## ตัวเลขขึ้นเวที

สแนปช็อตฐานข้อมูล 8 กันยายน 2569 มีบัญชีลงทะเบียน 1 บัญชี (ไม่ใช่หลักฐานลูกค้าจ่ายเงิน), รายการรับเงินที่ยืนยัน 0, เงินรับสุทธิที่ยืนยัน 0 บาท และข้อความ OA ที่ส่งสำเร็จ 0 รายการ ไม่มีการใส่ข้อมูล QA หรือยอดสมมติลงฐานจริง

รายชื่อในเครื่องและการโอนนอกระบบอาจยังไม่อยู่ในตัวเลขนี้ ให้ Now และ Ing ยืนยันจากการใช้งาน/ธนาคารก่อนเติมยอดล่าสุด ห้ามใช้จำนวนเครื่องจาก random ID แทนจำนวนครูแบบแม่นยำ และห้ามนับข้อมูล Demo เป็น traction

หากใช้มัดจำ 100 บาท ต้องบอกครูว่าชำระเงินแล้วจริง ระบุวิธีหักค่าบริการ/เงื่อนไขให้ชัด และแยกยอดมัดจำออกจากค่าสมาชิกที่ชำระเต็ม อย่าใช้ wrapper เปิด Pro ราคา 299 บาทเพื่อบันทึกมัดจำ 100 บาท ตัวเลือกมัดจำยังไม่มีข้อตกลงธุรกิจที่ทีมยืนยันให้ลงระบบ

## งานที่พักไว้

Omise, auth/legal registry รุ่นใหม่, erasure รายบุคคล และ backup/operations รุ่นใหม่ ถูกเก็บนอกชุดเผยแพร่ใน `.omx/deferred-omise/` และ `.omx/deferred-production/` พร้อม patch/snapshot ไม่ลบงานทิ้ง ไม่มี migration ชุดใหม่เหล่านี้ถูก apply ไปยัง Supabase จริง
