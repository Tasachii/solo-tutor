# Data inventory — Solo Tutor

อัปเดต 8 กันยายน 2569 · ข้อเท็จจริงจากโค้ดและ schema ปัจจุบัน (migrations 0001–0010) สำหรับให้ผู้เชี่ยวชาญกฎหมายใช้ทำ privacy notice / DPA · ช่อง **รอเจ้าของ** = ยังไม่มีการตัดสินใจ ห้ามเขียนลงนโยบายสาธารณะจนกว่าจะเติม

ผู้ให้บริการโครงสร้าง: GitHub Pages (หน้าเว็บ, สหรัฐฯ/CDN) · Supabase (ฐานข้อมูล/Auth/Edge Functions, ภูมิภาคสิงคโปร์, Free plan) · LINE Corporation (Messaging API ผ่าน OA ของครูเอง) · GitHub Actions (backup/monitoring, artifact ในสหรัฐฯ)

บทบาท (ต้องผู้เชี่ยวชาญยืนยัน): สำหรับข้อมูลนักเรียน/ผู้ปกครองที่ครูกรอก ครูเป็นผู้ควบคุมและ Solo Tutor เป็นผู้ประมวลผลตามคำสั่งครู **ยกเว้น** บัญชีครู, ตัวนับการใช้งาน, หลักฐานการเงินค่าสมาชิก, waitlist และ error report ซึ่ง Solo Tutor เป็นผู้ควบคุมเอง — ห้ามเหมารวมว่าเป็น processor ทั้งหมด

## สิ่งที่นโยบายปัจจุบัน (`src/copy/index.ts` → legal) ยังไม่ครอบคลุม

- retention ของชุด 6, 7, 8, 9, 10, 11 (ตอนนี้ "เก็บจนลบบัญชี" โดยพฤตินัย)
- การลบรายผู้ปกครอง (ชุด 5) และรายนักเรียนข้ามเครื่อง (tombstone — งาน B-05 ใน ledger)
- ชื่อนิติบุคคล/ที่อยู่/ช่องทาง DSAR/ผู้ตอบ และระยะเวลาตอบ (`legal.contact` ยังว่างโดยตั้งใจ)
- lawful basis สำหรับข้อมูลเด็กที่ครูกรอก (ครูเป็นผู้ควบคุม — ต้องมี DPA ระหว่างครูกับ Solo)
- subprocessor list ที่ผู้ใช้เห็น (GitHub, Supabase สิงคโปร์, LINE, Google ถ้าเปิด Sheets)

เอกสารนี้ไม่ใช่นโยบายและไม่ใช่สัญญา ใช้ประกอบ `docs/legal-review-draft.md` เท่านั้น
